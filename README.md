# Say It Slowly

A free daily picture puzzle I made. Say the pictures out loud, slowly, and they make a word or phrase. Five tries, a hint after two, and a streak to keep. No account, and your stats stay in your browser.

Play it at https://e13ctr0n1c.github.io/say-it-slowly/

It is plain HTML, CSS and JavaScript with no build step. To run it locally, serve this folder with any static server, for example `python3 -m http.server`, and open http://localhost:8000/.
